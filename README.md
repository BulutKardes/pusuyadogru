# 🔮 Pusuya Doğru – Quantum Discovery Engine

**Pusuya Doğru** is an experimental exploration platform that combines quantum randomness, artificial intelligence, and interactive mapping to generate unique exploration points based on user intention. Designed with a modern interface and AI-powered interpretation system, it transforms random coordinates into immersive discovery experiences.

---

## ✨ Features

- 🧭 Quantum-inspired coordinate generation
- ⚡ Attractor, Void & Blindspot discovery modes
- 🗺️ Interactive map powered by Folium
- 🤖 AI intention & synchronicity analysis with Groq (Llama 3.3)
- 💾 SQLite-based discovery journal
- 📱 Fully responsive Glassmorphism UI
- 🌌 ANU Quantum Random Number Generator integration with intelligent fallback
- 📍 One-click Google Maps navigation
- 📖 Persistent exploration history with AI insights

---

## 🛠️ Built With

- Python
- Streamlit
- Folium
- SQLite
- NumPy
- Pandas
- Groq API
- ANU Quantum Random Number Generator API

## 🚀 Getting Started

```bash
git clone https://github.com/yourusername/pusuya-dogru.git
cd pusuya-dogru

pip install -r requirements.txt

streamlit run app.py
```

---

## 🎯 How It Works

1. Set your starting location.
2. Choose a search radius and anomaly type.
3. Enter your intention or focus.
4. Generate a quantum-inspired discovery point.
5. Receive an AI-powered synchronicity interpretation.
6. Save your exploration to your personal journal.
